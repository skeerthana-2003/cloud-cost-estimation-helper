# Cloud Cost Estimation Helper

## About the Project
This is a beginner-friendly Python project that estimates cloud computing costs based on usage hours and an hourly rate.

The project demonstrates basic Python programming, user input, calculations, conditional statements, and error handling.

## Features
- Accepts usage hours and an hourly rate.
- Calculates the estimated total cost.
- Handles invalid inputs.
- Displays the result in a simple format.

## Technology Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the command:

python main.py

## Disclaimer
This is a learning project. The hourly rate is entered by the user and does not represent live AWS pricing or an actual cloud bill.
